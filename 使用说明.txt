几何共鸣 — 三种手势版

运行：解压全部文件，用 VS Code 的 Live Server 打开 index.html。
也可在该文件夹运行 python -m http.server 8000，访问 http://localhost:8000。
需要联网加载 p5 与 MediaPipe 模型。摄像头需允许权限；远程访问需 HTTPS。

三个手势
✊ 握拳保持约 0.45 秒：选择圆形。张开手后，拇指和食指捏合，保持变大，松开固定。
✌ 剪刀手保持约 0.45 秒：选择三角形。张开手后捏合，保持变大，横移调整角度，松开固定。
☝ 只伸出食指约 0.35 秒：立即从食指尖开始画曲线；移动手指留下轨迹，收起食指结束。
画曲线不需要捏合。由曲线切回圆形/三角形时，再做握拳/剪刀手。
切换形状时先张开手，是为了避免握拳被误当作捏合。
手掌正对摄像头、手指完整入镜、光照充足，更容易识别。

鼠标试画
点击“先用鼠标试画”。按钮或数字键 1/2/3 选择圆形/三角形/曲线。
按住拖动绘制，松开固定；触屏也可拖动。
C 清空，Z 撤销，S 保存图片，V 显示或隐藏摄像头。这些不是额外手势。
从鼠标模式返回摄像头：刷新页面后点击摄像头启动按钮。

代码结构与限制
基于原始课堂代码开发，PART A 手势关键点引擎保持原样。
PART B 新增基于关节角度及距离的三种手势规则，未额外加载 GestureRecognizer 模型。
规则输出的名称用于本项目，不代表模型返回的手势分类或置信度。
识别稳定等待用于过滤过渡动作；真实手型、遮挡和拍摄角度仍会影响识别。
圆形/三角跟踪丢失时取消正在画的一笔；曲线失去跟踪时保留已画轨迹。
每条曲线最多 2000 个采样点，达到后自动结束；收起食指再伸出可继续画。
保存只含已完成图形，不含摄像头、工具栏和光标。
声音：圆形/三角越大、曲线越长，音高越低；完成后响起铃声。
已检查语法和状态逻辑；实际摄像头识别、联网模型加载与音频需在你的设备实测。

部署：直接上传 index.html、style.css、sketch.js 到静态托管，入口 index.html，无需构建。

视觉更新：深蓝渐变背景、柔和蓝紫光晕、稀疏星点。曲线改为流星：前端亮点，尾部沿轨迹渐细渐淡，少量星尘。完成的曲线保留在画布上，不会自动消失；导出 PNG 也保留背景和流星效果。三种手势不变。

最新视觉：恢复原始红、橙、黄、青、蓝、米白、紫、深蓝随机配色；圆和三角保留渐变、柔光边缘与星尘。
曲线经过两轮圆滑处理，以连续渐细的带状路径绘制，消除逐段线条的接缝，保留流星亮点。
星光礼包：开始约 6 秒出现第一个，之后每隔随机 18–30 秒出现一个。指尖或鼠标靠近约 0.45 秒领取，爱心向四周散开并缓缓飘散，不改变画笔颜色。可通过“礼包”按钮关闭。
保存图片包含已完成的图形和背景，不包含礼包、爱心动画及提示文字。
